Hotel template feature overview

Pages & Structure

Hero

Home / Landing

Full-screen hero with hotel name, tagline, animated entrance, specials banner and dual CTA buttons

About

About Section

Two-column layout with hotel description, image, floating stat card and highlights grid

Rooms

Rooms Section

Room cards with image, price badge, description, feature checklist and per-room WhatsApp booking

Gallery

Gallery Section

6-image grid with hover overlays and a full lightbox viewer with arrow navigation

Reviews

Testimonials

Auto-rotating featured review, star ratings, dot indicators and clickable review cards

Contact

Contact Section

Contact info cards, enquiry form with date validation, WhatsApp redirect and Google Maps embed

Navigation & Global UI

Navbar

Smart Navbar

Transparent on load, turns solid on scroll. Desktop links + mobile hamburger menu with smooth open/close

WhatsApp

Floating Button

Fixed green WhatsApp button appears after scrolling 300px with a pulse ring animation for 6 seconds

Footer

4-Column Footer

Brand column, social media links, contact details, business hours and specials reminder card

Booking & Conversion Features

Booking

WhatsApp Booking

Every CTA pre-fills a WhatsApp message with hotel name and room details — zero friction for the guest

Enquiry

Smart Enquiry Form

Name, phone, check-in/out dates with validation (no invalid date ranges), and custom message

Specials

Specials Banner

Toggle on/off via config. Shows on hero and in footer. One line to update the deal copy

Maps

Google Maps

Embedded interactive map in the contact section so guests can find the hotel instantly

Animations & UX

Scroll

Scroll Animations

Every section fades and slides in using IntersectionObserver — no animation library needed

Hero

Hero Entrance

Staggered fade-in for each element, Ken Burns image zoom, animated gold divider line

Hover

Hover Effects

Room image zoom, gallery overlay reveal, nav link color shift, contact card shadow lift

Lightbox

Gallery Lightbox

Click any photo to open fullscreen. Arrow keys + keyboard Escape supported. Shows photo counter

Technical & Developer Features

Config

hotelData.js

Single file controls all content — name, rooms, phone, WhatsApp, highlights, testimonials, specials

Theme

theme.js

Two variables control the entire colour scheme — swap primary and secondary to rebrand in seconds

Stack

Next.js + Tailwind

Static-exportable, fast, SEO-ready. Hosted free on Vercel with auto-deploy on every git push

SEO

SEO Ready

Meta tags, Open Graph, JSON-LD structured data, sitemap.xml, robots.txt and favicon all configured

Mobile

Fully Responsive

Every section adapts to mobile. Navbar collapses to hamburger. Grid layouts reflow automatically

Social

Social Media Links

Facebook, Instagram, TikTok and X icons in the footer — all configurable per client in hotelData
